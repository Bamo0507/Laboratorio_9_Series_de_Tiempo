# **Laboratorio 9 - Series de tiempo**

Este laboratorio aborda el pronóstico del consumo eléctrico mediante series de tiempo. Se exploran y preparan los datos, se construyen y comparan modelos estadísticos, de aprendizaje automático y neuronales, y se evalúan sus predicciones respetando el orden temporal. También se analiza el efecto de la historia disponible, las estrategias de predicción y el uso de modelos globales, locales y fundacionales.
